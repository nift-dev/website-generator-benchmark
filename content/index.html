Methodology

Equivalent small pages, tool-native fixtures.

Equivalent small pages generated from tool-native source; dependency installation and fixture generation are outside timed runs.

  • 10,000 pages per fixture.
  • 1 warmup before timing.
  • 3 measured clean builds retained per generator.
  • Generated output and relevant build caches removed between measured builds.
  • Dependency installation and fixture generation excluded from the timed region.
  • The harness refuses to write partial comparison evidence when a requested tool is missing or fails.

Reproduce it

Run the same harness yourself.

The benchmark repository contains the fixture generator and pinned competitor setup. On a Linux/macOS machine with a built Nift binary:

./scripts/setup-tools.sh

python3 -u scripts/benchmark.py \
  --nift /path/to/nift \
  --hugo .benchmark-tools/hugo \
  --node-project . \
  --pages 10000 \
  --warmups 1 \
  --repetitions 3 \
  --output evidence/results.json

The benchmark is intentionally reproducible rather than instant: Astro and VitePress take substantially longer than Nift/Hugo on this workload.

Interpretation

What this does—and does not—show.

It does show

On this deterministic 10,000-page clean-build fixture, Nift had the lowest measured median by a large margin.

It does not show

That Nift is universally faster on every workload, or that clean builds are equivalent to each framework's intended dev-server/HMR experience.

Why publish it

The differences are large enough to invite skepticism. Publishing the harness and raw samples makes that skepticism testable.
